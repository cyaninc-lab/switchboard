## Switchboard 0.1.19

- **Copy buttons.** Every code block in a reply has a Copy button, and hovering a reply shows a button that copies the whole reply.
- **@ to mention a file.** Type @ and a few letters in the message box to pick a file from the session's folder; Claude reads it.
- **Drag things around.** Drag projects to reorder them (every device sees the same order), drag a tab out of the window to give it its own window, and on Windows dragging tabs and dropping images now work.
- **Sessions sort themselves.** Within a project, the most recently active session is on top (pinned ones first). The list holds still while your pointer is over it.
- **Remove or delete from the right-click menu.** Remove from tree takes a session off the list; Delete for good, at the bottom, deletes it from its machine after you type its name.
- **Three font choices.** Pick separate fonts for the interface, the chat and code. Streamed replies no longer switch font when they finish.
- **Clickable file paths in steps.** The file in an Edit, Write or Read step opens like paths in replies.
- **Slimmer scroll bars**, and a bigger text size no longer makes the whole window scroll.
