## Switchboard 0.1.13

- **Choose the project when adding.** In Add, the Project box is now a list: the folder's name (as before), any project you already have, or "New project…". Works for new sessions too.
- **Text size and fonts.** Settings has a text size (90–130%, the whole app scales) and a choice of interface font and chat/code font. Each device remembers its own.
