## Switchboard 0.1.37

- **Agents can set up their own watches:** a session can have Switchboard check something for it (a schedule, a command, a website, a GitHub repo) and wake it, or just tell you. It can pause and remove them too, and if no kind of watch fits, it sends you a "watch idea". You see every watch an agent sets up in your inbox and the Watches panel.
- **Connections recover by themselves:** after a network change (a VPN switching on, Wi-Fi changing) the desktop app reconnects instead of needing a restart; machines that drop off the relay are back within seconds; "can't reach" says how a machine is reached, when it last answered and why.
- **History loads fast:** going back to a session you just looked at is instant, and long sessions open far quicker.
- **Unread messages:** what you send while Claude works stays at the bottom with a 🕒 until Claude reads it, and is still there if you close and reopen the app.
- **Thinking shows as a normal message** (when there's any text in it).
- **Windows:** "Keep agents running when Switchboard is closed" now works on Windows too (a task that starts when you log in).
