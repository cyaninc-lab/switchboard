## Switchboard 0.1.20

- **Split view.** Right-click a session → Open to the side, or Open below, to see two sessions at once. Drag the divider to resize; flip between side by side and stacked.
- **/btw side chat.** Type `/btw` and a question: the answer opens on the right, knows what's been said, and never goes into the session.
- **Background tasks.** Commands Claude runs in the background show in a bar above the message box, with how long they've run, their output and a Stop button.
- **Removed list.** Removing a session keeps its name, project and settings; restore it from Removed under the session list, or delete it for good there.
- **Defaults for new sessions.** Settings → New sessions: the mode, model, effort and account new sessions start with. The footer now shows what "default" means (for example "Default · Opus 5.5").
- **Line numbers on edits**, from Claude Code's own record of the change.
- **Drag a session to another project** in the list.
- **Send bug reports from the app.** Report a bug → Send to GitHub (one-time GitHub sign-in), or Open on GitHub instead as before.
- **Watches:** only at certain times (e.g. weekdays 8:30–17:30), "only tell me when there's something new", and an "Ask Claude to check something" starting point.
- **Fixes:** `/clear` no longer brings the old conversation back after a restart; right-click menus stay inside the window.
